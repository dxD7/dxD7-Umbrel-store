# dxD7-Umbrel-store

A community [umbrelOS](https://umbrel.com) app store: my Umbrel app packages, installable directly from this repo.

> Unofficial community package. Not affiliated with Umbrel, or with the developers of any app listed here.

## Add this store to umbrelOS

1. In umbrelOS go to **App Store → ⋯ → Community App Stores** and add:
   ```
   https://github.com/dxD7/dxD7-Umbrel-store
   ```
2. The apps below appear in the store. Install any of them as usual.
